자주 묻는 질문

구매를 어떻게 복원하나요?

게임에서 상점을 열고 구매 복원을 탭하세요. 구매할 때 사용한 것과 같은 Apple ID 또는 Google 계정을 사용해야 합니다. 광고 제거는 즉시 복원되며, 코인 팩은 소모성 상품이므로 복원할 수 없습니다.

광고 제거는 무엇을 하나요?

배너 광고와 근무 사이의 광고를 영구적으로 숨깁니다. 보상형 동영상은 사용자가 직접 시작하는 선택형 보너스로 그대로 남습니다. 코인은 포함되지 않습니다.

광고를 꼭 봐야 하나요?

아니요. 무료 게임에는 배너 광고와 근무 사이의 광고가 표시되며, 보상형 동영상은 사용자가 시청을 탭할 때만 재생됩니다.

언어는 어떻게 바꾸나요?

설정 화면을 열고 언어를 선택하세요. Gapfly는 기본적으로 기기 언어를 따릅니다.

플레이어 번호는 어디에서 확인하나요?

게임의 설정 화면에 표시됩니다. 데이터 삭제 또는 사본 요청 시 사용자의 데이터를 찾기 위해 이 번호가 필요합니다.

새 휴대폰으로 진행 상황이 옮겨지나요?

계정이 없으므로 진행 상황은 사용자의 기기에만 저장됩니다. 새 기기나 새로 설치한 경우에는 처음부터 시작합니다. 휴대폰 자체 백업으로 데이터가 복구될 수도 있지만, 당사는 이를 보장할 수 없습니다.

코인이나 팁이 사라졌어요

같은 기기를 사용 중이며 게임 데이터를 지우지 않았는지 확인해 주세요. 구매했는데 코인이 지급되지 않았다면 스토어 영수증 또는 주문 번호와 플레이어 번호를 적어 문의해 주세요.

게임이 충돌했거나 뭔가 제대로 작동하지 않아요

먼저 최신 버전으로 업데이트하세요. 문제가 계속되면 게임 설정의 문제 신고를 이용하거나, 간단한 설명과 문제가 생기기까지의 단계를 적어 이메일로 보내 주세요.
